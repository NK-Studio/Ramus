## 1. 목적

Unity 에디터 안의 Git 클라이언트(`com.nkstudio.gitvcs`)를 Unity 밖에서 혼자 도는 데스크톱 앱으로 옮긴다.
1.0.0 은 **원본 1.1.0 과 같은 화면과 같은 쓰임새**를 갖춘 첫 정식 버전이다. 원본 사용자가 옮겨 와도 "모양이 다르다·이게 없다" 고 느끼지 않는 것이 목표다.

### 1.1 대상 플랫폼

| 플랫폼 | 지원 | 비고 |
|---|---|---|
| macOS Apple Silicon (arm64) | 지원 | 12.0 이상, WKWebView |
| Windows 10/11 x64 | 지원 | WebView2 (Windows 11 기본 포함, 10 은 런타임 설치) |
| macOS Intel | 지원 안 함 | |
| Linux | 지원 안 함 | 빌드는 막지 않음 |

### 1.2 범위

- **포함**: 원본 1.1.0 의 Git 창·보조 창·설정의 모든 화면과 동작 중 Unity 와 상관없는 것. 원본에 없던 레포지토리 열기·탭·Clone.
- **제외(Unity 전용)**: Project 창 상태 아이콘·우클릭 메뉴, 에셋+`.meta` 묶기와 빠진 `.meta` 확인, 메인 툴바 확장, Safe Mode 방지, 씬·프리팹 저장 확인, 에셋 다시 임포트·Ping, PSD/PSB 미리보기, 에디터 스킨 아이콘, Unity 6.0 우회 코드.
- **원본과 다르게 하는 것**: "Unity 프로젝트 = 레포지토리" 가 아니므로 레포지토리 열기·최근 목록·탭·Clone 을 둔다. 메뉴 모양(OS/테마) 설정은 웹뷰에서 OS 메뉴를 쓸 수 없어 테마 메뉴 하나로 한다.

### 1.3 원칙

1. **PC 에 설치된 `git` CLI 를 실행한다.** LibGit2 를 쓰지 않는다. 사용자의 `.gitconfig`·자격 증명 도우미·LFS 를 그대로 쓴다.
2. **사용자의 설정 파일을 바꾸지 않는다.** 앱 설정(SSL 등)은 git 호출마다 `-c` 로만 붙인다.
3. **비밀번호를 파일·명령줄에 남기지 않는다.** SSH 비밀번호는 환경 변수로만 넘기고 앱을 끌 때까지 기억한다.
4. **사용자에게 보이는 글은 한국어.** 코드·명령·경로·식별자·git 원문은 그대로 둔다.
5. **되돌릴 수 없는 작업은 묻는다.** 버리기·Hard reset·강제 삭제·원격 삭제. 위험한 확인은 Enter 기본값이 취소다.

## 3. 구조

### 3.1 크레이트

| 이름 | 종류 | 맡는 일 |
|---|---|---|
| `ramus-core` | lib | git 실행(`GitRunner`), 파서(status·log·diff·refs·충돌), 그래프 배치, 부분 패치, SSL·로그인, 설정. 화면과 무관하고 테스트로 확인한다 |
| `ramus-app` | bin | tao 창 + wry 웹뷰, IPC 분배, 작업 스레드, 파일 감시(notify), 자동 페치, 파일·폴더 고르기(rfd) |
| `ui/` | 정적 파일 | HTML·CSS·JS(빌드 도구 없음). 실행 파일에 묻어 `gitvcs://`(Windows `http://gitvcs.localhost`)로 제공 |

### 3.2 메시지

- 화면 → Rust: `window.ipc.postMessage({id, cmd, args})`
- Rust → 화면: `__gitvcs.reply({id, ok, value | error})`, 요청 없는 알림은 `__gitvcs.event({event, data})`(`changed`·`fetching`·`fetched`)
- 오류는 `{message, ssl, auth, login}` 으로 온다. 화면이 해결 안내·로그인 창을 고른다.
- git 은 모두 작업 스레드에서 돈다. 레포지토리를 바꾸는 작업은 하나씩(쓰기 잠금).

### 3.3 개발 도구

- 디버그 빌드 + `RAMUS_DEV_PORT` 로 점검 통로를 연다(JS 를 웹뷰에서 실행). 릴리스 빌드에는 들어가지 않는다.
- `RAMUS_UI_DIR` 로 화면 파일을 디스크에서 읽는다. `RAMUS_SETTINGS` 로 설정 파일 위치를 바꾼다.

## 5. 비기능 요구사항 (NF)

| ID | 요구 | 수용 기준 |
|---|---|---|
| NF-01 | 시작 | 마지막 레포지토리가 있는 상태에서 앱을 켜고 그래프가 보일 때까지 1.5초 이내(1만 커밋 레포지토리, M 계열 Mac) |
| NF-02 | 그래프 성능 | 5만 커밋 레포지토리에서 스크롤 60fps 유지, 새로고침 1초 이내 |
| NF-03 | diff 성능 | 10만 줄 diff 가 1초 안에 열리고 스크롤이 끊기지 않는다(가상화) |
| NF-04 | 화면 멈춤 없음 | git 은 모두 작업 스레드. 네트워크 작업 중에도 화면 조작이 된다 |
| NF-05 | 바깥 변경 반영 | 편집기 저장·터미널 git 이 2초 안에 반영된다. 반영 때 입력란 포커스·누르던 버튼·diff 고른 줄을 잃지 않는다(내용이 같으면 다시 그리지 않음) |
| NF-06 | 보안 | 비밀번호·토큰을 설정 파일·명령줄·로그에 남기지 않는다. 사용자 `.gitconfig` 를 바꾸지 않는다. 웹뷰는 앱 화면 주소만 연다. 개발 점검 통로는 릴리스에 없다 |
| NF-07 | 안전 | 되돌릴 수 없는 작업은 확인을 거친다. 레포지토리 밖 경로(`..`)는 거절한다. 설정 파일은 원자적으로 쓴다 |
| NF-08 | 한글·특수 경로 | 한글·공백·`[ ]` 가 든 경로, CRLF 파일, 끝 개행 없는 파일에서 모든 작업이 된다 |
| NF-09 | 한글 입력 | 커밋 메시지·검색·편집기에서 한글 IME 조합이 끊기지 않고, 조합 중 Enter 가 확인으로 처리되지 않는다 |
| NF-10 | 키보드 | 주요 작업에 단축키(⌘/Ctrl+Enter 커밋, ⌘/Ctrl+Z 실행 취소, ⌘/Ctrl+F 찾기, F5 새로고침, Esc 닫기). 목록·트리·메뉴는 키보드로 움직인다 |
| NF-11 | 크기 | 릴리스 실행 파일(macOS .app) 15MB 이하. 글꼴·아이콘 포함 |
| NF-12 | 플랫폼 | macOS arm64·Windows x64 에서 같은 화면. Windows 는 콘솔 창을 띄우지 않는다. 파일 관리자·터미널 열기는 OS 에 맞게 |
| NF-13 | 국제화 | 화면 글은 한 곳(문자열 표)에 모은다. 1.0.0 은 한국어, English 는 같은 표로 추가할 수 있게 |
